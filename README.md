<h1 align="center">ITBOOK – Website bán sách có tìm kiếm bằng giọng nói</h1>
🎯<b>Giới thiệu</b> <br />
ITBOOK là website bán sách trực tuyến cho phép người dùng: <br />
- Xem & tìm kiếm sản phẩm nhanh <br />
- Tìm kiếm bằng giọng nói (Speech Recognition) <br />
- Mua hàng & thanh toán qua MoMo <br />
- Quản lý thông tin cá nhân và đơn hàng <br />
Dự án giúp mình thực hành mô hình PHP thuần kết hợp Ajax, quản lý cơ sở dữ liệu và làm việc với API thực tế. <br />
